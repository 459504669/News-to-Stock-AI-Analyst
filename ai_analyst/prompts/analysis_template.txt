标题：{title}

正文内容：

## 输出要求

请严格按照以下 JSON 格式输出，**不要输出 JSON 以外的任何内容**：

```json
{{
  "rating": <1~5的整数>,
  "rating_label": "<强烈利空/利空/中性/利好/强烈利好>",
  "summary": "<300~500字的分析摘要，深入浅出，逻辑清晰>",
  "beneficiary_sectors": ["<受益板块1>", "<受益板块2>", ...],
  "recommended_stocks": [
    {{"code": "<股票代码>", "name": "<股票名称>", "logic": "<推荐逻辑>"}},
    ...
  ],
  "risks": ["<风险点1>", "<风险点2>", ...],
  "time_horizon": "<short/medium/long>",
  "time_horizon_label": "<短期/中期/长期>",
  "confidence": <0.0~1.0的置信度>
}}
```

## 分析要点

1. **rating 评分标准**：
   - 1分 = 强烈利空：对资本市场有重大负面冲击
   - 2分 = 利空：对相关板块有明显压力
   - 3分 = 中性：影响有限或方向不明确
   - 4分 = 利好：对相关板块有积极推动
   - 5分 = 强烈利好：重大政策红利或产业催化

2. **beneficiary_sectors**：选择 A 股/港股最直接受益的 2~4 个板块（如：新能源、半导体、消费、医药等）

3. **recommended_stocks**：给出 3~5 个具体标的，必须包含股票代码（A 股用.SH/.SZ 后缀，港股用.HK 后缀）

4. **risks**：列出 1~3 个需要警惕的风险因素

5. **time_horizon**：
   - short = 短期影响（1~5 个交易日）
   - medium = 中期影响（1~4 周）
   - long = 长期影响（1 个月以上）

6. **confidence**：你对本次分析结论的置信度（0.0~1.0）
